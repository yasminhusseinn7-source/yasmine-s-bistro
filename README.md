# 🍽️ Yasmine's Bistro - Landing Page

Welcome to **Yasmine's Bistro**, a modern and responsive restaurant landing page built with passion for clean code and elegant design.

## 🚀 Project Overview
This project is a static website designed to showcase a restaurant's menu, atmosphere, and contact information. It focuses on high-quality visuals and a smooth user experience.

## 🛠️ Built With
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling and animations.
- **Google Fonts:** For modern typography.

## ✨ Features
- **Fully Responsive:** Works perfectly on Desktop, Tablet, and Mobile.
- **Interactive Menu:** Clean layout for food items and prices.
- **Modern UI:** Focused on a professional "Bistro" aesthetic.
